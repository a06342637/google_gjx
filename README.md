# 工具箱

一个完全本地加载的 Chrome Manifest V3 扩展（当前版本 v1.6.3），提供：

- Base32 TOTP 2FA 验证码生成与本机保存管理
- 6–36 位安全随机密码生成
- 混合姓名库的美国英文姓名生成
- 浅色/深色主题切换

## 本地安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹：`C:\Users\adminuser\Documents\google插件`。
5. 将“工具箱”固定到 Chrome 工具栏后即可使用。

修改文件后，可在 `chrome://extensions` 中点击插件卡片上的刷新按钮重新加载。

## 使用方法

### 1. 美国假人名

打开插件后，第一张卡片会显示一个由英文名和姓氏组成的测试姓名。点击右侧刷新按钮生成新的姓名，点击复制按钮写入剪贴板。姓名由公共姓名接口和内置词库混合生成，不需要填写任何个人信息。

### 2. 随机密码

在第二张卡片中：

- 拖动“长度”滑杆，范围为 6–36 位。
- 分别开启或关闭大写、小写、数字和特殊字符。
- 点击刷新按钮生成新密码，点击复制按钮复制当前密码。

插件会保证密码包含所有已启用的字符类型。密码使用浏览器 Web Crypto 安全随机数生成，不会保存或上传。

### 3. 2FA 验证码

在第三张卡片中粘贴网站提供的 Base32 TOTP 密钥，例如 `JBSWY3DPEHPK3PXP`。插件会显示 6 位动态验证码和倒计时，并在首次生成时自动复制。

- 输入名称后点击“保存”，可以把密钥保存在本机浏览器。
- “已保存 2FA”默认收起，点击“展开”后可以搜索、查看、复制、编辑和删除。
- 密钥只保存在本机 `chrome.storage.local`，当前版本未使用主密码加密，请勿在不可信的电脑上保存重要密钥。

## 版本下载

每个版本都会在 GitHub 的 [Releases](https://github.com/a06342637/google_gjx/releases) 页面提供 ZIP 下载包。下载后解压，再按上面的步骤加载解压后的文件夹即可。

后续发布新版本时，只需更新 `manifest.json` 中的版本号，提交并推送同名 Git 标签（例如 `v1.6.4`）。GitHub Actions 会自动打包扩展并在 Releases 页面生成对应下载文件。

## 隐私与安全

- 2FA 密钥保存在 `chrome.storage.local`，不会发送到任何服务器。
- 保存的 2FA 密钥未使用主密码加密，请仅在可信的本机浏览器资料中使用。
- 密码生成完全离线，并使用 Web Crypto 安全随机数。
- 美国姓名功能使用公共姓名接口与内置姓名库组合生成，不展示联网/断网状态。
- 插件不申请网页访问权限，不读取或修改当前网页。

## 权限

- `storage`：保存 2FA 项目和主题偏好。
- `clipboardWrite`：复制验证码、密码和姓名。
- `https://randomuser.me/*`：获取随机美国姓名。
